# 🤝 Plataforma de Doações Comunitárias

## 📌 Sobre o Projeto
Este projeto consiste no desenvolvimento de um MVP (Mínimo Produto Viável) de uma plataforma web de doações comunitárias, com foco na conexão entre doadores e campanhas sociais da cidade de Tijucas - SC.

O sistema foi desenvolvido como parte da Etapa 1 do projeto acadêmico, com o objetivo de validar a proposta de valor e as principais funcionalidades da aplicação.

---

## 🎯 Objetivo
Criar uma solução simples, intuitiva e acessível que permita:
- Visualizar campanhas de doação
- Conhecer instituições locais
- Simular ações de doação
- Realizar login no sistema

---

## 🚀 Funcionalidades

✅ Listagem de campanhas com:
- Nome da campanha
- Descrição
- Meta de arrecadação
- Valor arrecadado
- Barra de progresso

✅ Sistema de doação (simulado)
- Botão "Doar"
- Feedback de confirmação

✅ Tela de instituições
- Listagem de organizações parceiras

✅ Sistema de login (simulado)
- Entrada de email e senha
- Mensagem de sucesso

---

## 🖥️ Tecnologias Utilizadas

- HTML5

## 📊 Melhorias Futuras

1. Integração com banco de dados

---

## Melhorias atualizadas no projeto:
1. ✅ Integração com banco de dados (PostgreSQL)
- As campanhas, usuários e doações passaram a ser armazenados de forma persistente, garantindo que as informações não sejam perdidas ao recarregar a aplicação.

2. ✅ Sistema real de autenticação
Foi implementado um sistema completo de cadastro e login, permitindo:
- Criação de contas
- Validação de credenciais
- Controle de acesso às funcionalidades (ex: doações)

3. ✅ Processamento de doações funcional
O sistema agora registra doações reais no banco de dados, permitindo:
- Atualização automática dos valores arrecadados
- Associação entre usuário e campanha
- Simulação realista de funcionamento da plataforma

4. ✅ Cadastro de usuários
- Usuários podem se cadastrar diretamente na plataforma, possibilitando interação completa com o sistema.
